# Reference results

This directory stores compact reference outputs used to check reproduction.

## Synthetic benchmark

The committed tables summarize the 1,300-image controlled rectangle experiment:

- 800 images: n=0, r=1,...,8, 100 images per condition.
- 500 images: r=5, n=0,...,4, 100 images per condition.
- Cellular Euler check: chi_cell=2 in 1,300/1,300 constructions.

## BreaKHis 40X

The committed compact outputs summarize the patient-grouped predictive experiment:

- 1,995 images.
- 625 benign / 1,370 malignant.
- 81 patients.
- 5 outer folds x 5 repeats.
- 4 inner folds.
- 2,000 patient-level bootstrap resamples.

The large per-image feature matrix and full OOF-prediction file are intentionally
not committed here; they are regenerated by the BreaKHis notebook and included
in its exported result bundle.

Reference paired result:

- Full HIG - RAG cross-fitted ROC-AUC difference approximately -0.005.
- 95% patient-bootstrap CI approximately [-0.036, 0.028].

The interval includes zero; the repository does not encode a claim of predictive
superiority of the full HIG over the RAG under this protocol.
